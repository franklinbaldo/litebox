================================================================================
CRITICAL FUNCTIONS FOR WINDOWS ARM64
================================================================================

MUST IMPLEMENT:

1. update_host_tls_entry()
   - Called BEFORE every switch_to_guest()
   - Uses TPIDRRO_EL0 as key
   - Uses atomic CAS for thread safety
   - Supports tombstone reclamation (like macOS)

2. switch_to_guest()
   - Loads guest_tpidr from TCB offset 24
   - Writes to TPIDR_EL0
   - Loads guest_x18 from TCB offset 40
   - TCB pointer passed explicitly (not TPIDR_EL0)

3. remove_host_tls_entries()
   - Called when thread exits
   - Writes tombstone (0) to free slot
   - Enables slot reclamation by other threads

MUST NOT DO:

1. Don't rely on TPIDR_EL0 to find TCB
   (Windows context switches may clobber it)

2. Don't use different offsets for guest_tpidr/guest_x18
   (Must match macOS: 24 and 40)

3. Don't initialize TLS table entries with non-sentinel values
   (All must start as 0xFFFFFFFFFFFFFFFF)

4. Don't use host TPIDR_EL0 as table key
   (Use TPIDRRO_EL0 like macOS does)
