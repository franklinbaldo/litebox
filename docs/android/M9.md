# M9 — Windows input to Android interaction

Parent RFC: #25. Stacked on M8 / PR #35.

## Goal

Close the first visual Android loop by translating bounded Windows window input into Android input events that reach a real Activity/View hierarchy.

## Input path

```text
Win32 mouse / keyboard / window events
  -> LiteBox android-input capability
  -> normalized guest input records
  -> Android input path
  -> Activity / View dispatch
```

The host bridge translates only explicitly supported event classes. It does not expose raw host handles, arbitrary Windows messages or global input hooks to the guest.

## First interaction contract

Support only what the first acceptance APK needs:

- pointer move/down/up inside the LiteBox window;
- primary-button click;
- basic keyboard key down/up for a bounded key set;
- focus enter/leave and deterministic loss-of-focus cleanup;
- coordinate mapping for the fixed M8 virtual display.

Touch gestures, IME, multitouch, gamepads, global hotkeys and accessibility bridges are follow-up work.

## End-to-end acceptance APK

The first visible fixture contains one Activity with:

- text: `Hello from Android on LiteBox`;
- one Android `Button`;
- button click changes the displayed text;
- deterministic close/exit behavior.

The click must travel through the Windows window, LiteBox input bridge and Android dispatch path; directly invoking the Java callback does not satisfy the gate.

## Acceptance

- [ ] Win32 pointer events are normalized and bounds-checked
- [ ] Android receives pointer down/up at the expected View coordinates
- [ ] real Android Button click handler executes
- [ ] updated UI is rendered through M8 and becomes visible in the same HWND
- [ ] keyboard fixture reaches Android dispatch for the supported bounded key set
- [ ] focus loss cannot leave a stuck pressed pointer/key state
- [ ] no admin, VM, WSL, Hyper-V/WHPX, QEMU, kernel driver, service installation or global input hook is required

Passing M9 is the first point where LiteBox can credibly claim a minimal interactive Android GUI application on ordinary Windows userland.
